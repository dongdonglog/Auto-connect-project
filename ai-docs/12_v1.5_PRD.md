# Material Map v1.5 PRD：AI 原生视觉知识地图

状态：已确认，实施基线。目标版本：`v1.5`。

## 1. 产品定义

Material Map v1.5 是一个本地优先的视觉知识地图。用户把材料放入主题画板，看到材料之间有证据支持的关系，并让 AI 围绕当前选区生成可审核的分组、关系、卡片和布局草案。

一句话：**选中一组材料，AI 帮你搭出一张可解释、可撤销的知识地图。**

产品不以阅读器细节、通用聊天或自动全库建图为中心。正式知识结构仍由用户确认，原始文件仍由用户管理。

## 2. 目标用户与目标

目标用户是整理技术文档、项目资料、学习材料和个人文件的泛知识管理用户。

v1.5 目标：

1. 让主题画板成为第一视觉信号，形成自由画板和流程图两种稳定视图。
2. 让用户完成“选择材料 -> AI 生成计划 -> 预览差异 -> 审核应用 -> 撤销/重做”闭环。
3. 把分组、关系、卡片样式和布局变成结构化、可追踪、可拒绝的 proposal。
4. 在不破坏 v1.0 工作区的前提下，提升大图性能、备份恢复和发布可靠性。

## 3. 核心流程

```text
工作台 / 主题画板
  -> 选择材料或当前分组
  -> 输入整理指令（可选）
  -> AI 读取有限上下文
  -> 返回结构化 Canvas Plan
  -> 画布显示 diff overlay
  -> 用户逐项或批量应用 / 忽略
  -> 正式画板写入原子历史
```

AI 可以提出：创建关系、创建 workstream、重命名关系、调整卡片样式、调整顺序和布局。AI 不得自动删除材料、修改原始文件或绕过审核直接写入正式关系。

## 4. 功能范围

### 4.1 画板

- 自由画板 `map`：保留用户位置、手动连线和样式。
- 流程图 `flow`：按正式关系自动排列，不覆盖自由画板坐标。
- workstream 分组容器：显示标题、颜色、成员数量，支持折叠和展开。
- 选区聚焦：仅查看选中卡片及其一跳关系；可切换“只看已确认关系”。
- 画板偏好持久化：主题记住视图模式和过滤状态。
- 大图渲染优化：减少无关节点、边和布局计算对交互的影响。

### 4.2 AI 画板共创

- 选区整理：根据选中材料提出分组、关系和卡片展示建议。
- 语义补全：为关系生成简短标签、理由和证据摘要。
- 布局建议：生成卡片位置和流程方向的可审核草案。
- 差异预览：新增、修改、移动和分组均在正式应用前可见。
- 批量审核：支持全选应用、全选忽略和逐项处理。
- 冲突保护：主题 revision 变化后，旧 proposal 不得覆盖用户新修改。

### 4.3 数据可靠性

- 工作区导出包增加 manifest、schema 版本和校验信息。
- 恢复前检查包完整性，恢复后验证材料、关系、分组、样式、proposal 和历史。
- 保留 v1.0 表和字段的兼容读取；迁移只增不删。
- JSON 结构导出作为诊断和自动化接口，不替代 `.material-workspace` 完整备份。

### 4.4 AI 与隐私

- 云端模型优先，本地 Ollama 等 provider 兼容。
- 云端调用前必须启用并确认云端材料授权。
- UI 显示本次发送的材料数量、上下文范围、provider 和模型。
- 模型失败、超时、限流、非法 JSON 或拒绝访问时，画板和本地编辑继续可用。

## 5. 成功指标

| 指标 | v1.5 标准 |
| --- | --- |
| AI 安全性 | 任何未审核 AI 请求不得改变正式关系、材料或布局 |
| 冲突安全 | 过期 proposal 不能覆盖新 revision |
| 画板规模 | 100 张卡片可正常拖拽缩放，300 张可操作，500 张有可复现基准 |
| 恢复可靠性 | v1.0 工作区可导入；导出/恢复后核心数据一致 |
| 可撤销性 | 每次批量应用是一个可撤销历史单元 |
| 降级能力 | AI 不可用时，本地画板和关系探索不受阻 |

## 6. 非目标

账号、云同步、多人协作、移动端、网页端、插件市场、全库自动建图、AI 静默改图、原始文件写入、Neo4j/Elasticsearch/远程数据库，以及 PNG/SVG 作为核心阻塞项均不在 v1.5 核心范围。
