# Material Map v1.5 执行计划

状态：已确认，目标周期 8-10 周。目标平台：Windows x64、macOS arm64。

## 阶段 0：数据与接口基线（第 1 周）

- 冻结 `CanvasAiRequest`、`CanvasAiPlan`、`CanvasAction` 和 proposal IPC。
- 添加 proposal run、base revision、source 和主题视图偏好的迁移。
- 增加工作区 manifest、schema 版本、校验和和恢复前完整性检查。
- 将 proposal 应用逻辑从大文件中抽出为可单测的内部服务。

验收：v1.0 工作区可打开、导出、导入；旧 proposal 和正式关系不丢失。

## 阶段 1：画板基础升级（第 2-4 周）

- workstream 分组容器、折叠/展开、颜色和成员数量。
- 选区聚焦、“只看已确认关系”和视图偏好持久化。
- 稳定节点/边数据，减少无关 render 和重复 layout。
- 建立 100/300/500 卡片性能脚本和记录格式。

验收：map/flow 切换不覆盖自由坐标，分组状态刷新和重启后保持，大图基准可复现。

## 阶段 2：AI plan 与 proposal diff（第 5-7 周）

- 实现上下文裁剪和云端/本地 provider 调用。
- 严格解析和校验模型 JSON，只生成 proposal run。
- 画布 overlay 显示新增关系、移动位置、分组和样式差异。
- 支持逐项应用、批量应用、全部忽略、过期提示和重新生成。

验收：任何 AI 失败或未授权都不写正式数据；所有应用均可撤销。

## 阶段 3：一致性与发布收口（第 8-10 周）

- revision 冲突、原子批量事务和 undo/redo 回归。
- JSON 诊断导出、工作区恢复校验、数据健康提示。
- 补快捷键、loading、空态和错误态。
- 完成 Windows/macOS 打包、安装、Portable/DMG、文件监听和恢复验收。
- 有余量时补 PNG/SVG 视觉导出。

## 测试矩阵

| 层级 | 必测场景 |
| --- | --- |
| 单元 | JSON 校验、action 归一化、revision、迁移、map/flow 和分组布局 |
| 集成 | provider 未授权、超时、限流、非法 JSON、未知材料 ID、批量回滚 |
| E2E | 选择材料 -> AI plan -> diff -> 部分应用 -> 冲突 -> 撤销/重做 |
| 性能 | 100/300/500 节点加载、缩放、拖拽、关系边和自动布局 |
| 发布 | Windows x64、macOS arm64、导入导出、文件夹监听和旧工作区恢复 |

## 发布门槛

`npx tsc --noEmit`、`npm run test:ci`、`npm run build`、`npm run test:e2e` 全部通过；性能基准和恢复报告随版本归档；云端 AI 仍必须显式授权。
