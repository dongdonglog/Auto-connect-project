# 08 MVP 开发计划

目标：完成可发布的 0.1 本地知识探索器。优先完成可解释文件关系闭环，不扩展聊天或自动全库画布。

## 里程碑 0：基线收敛

完成：技术文档统一为 Electron/SQLite；Explorer、材料关系 schema 与主题画板编辑器已存在。

验收：文档、README、产品文案不再承诺 Go/Python 服务化或 AI 默认建图。

## 里程碑 1：关系引擎正确性

1. 将显式引用解析扩展到 Markdown link、相对路径、代码 import，并解析到工作区 material。
2. 完成受控实体词表、通用词抑制、实体提及位置和增量重算。
3. 明确保留/隐藏状态的无向 pair 迁移，避免方向变化丢失用户选择。
4. 给 20-50 份样本建立性能基准：导入后关系查询 P95 小于 1 秒。

验收：引用关系优先于实体关系；通用词不造成全连接；索引单文件不全量重建。

## 里程碑 2：Explorer 闭环

1. 完善 Explorer 的 loading、空态、证据定位/高亮和材料导航。当前 loading、空态、材料导航、证据来源跳转、隐藏关系恢复和阅读器内定位/高亮已完成。
2. 固定关系时自动加入用户选择的主题，或在无主题时提供“创建主题并固定”操作。
3. 隐藏、固定、删除材料、重新索引和工作区恢复的状态回归测试。

验收：用户无需 AI 即可完成“打开 -> 看关联 -> 看证据 -> 固定 -> 在画板编辑”。

## 里程碑 3：画板与遗留功能收敛

1. 删除旧 App 内未使用工作台、画板和预览组件。
2. 移除旧主题候选虚线、批量 AI 精炼在主 UI 的入口；保留历史数据读取兼容。
3. 完成四边端口、多边样式、DAG 布局与大图性能测试。当前四边端口、16 种端口组合单测、单向默认连线、关系样式、原子命令历史、端点重连和避障路由已完成；完整 UI 组合回归与大图性能记录待补。

验收：只有一套画板组件、一个关系发现入口和一个正式关系模型。

## 里程碑 4：AI 与发布

1. 单条 AI 解释增加超时、模型未配置、云端同意、结构化输出测试。当前这些服务级测试已完成，待补 UI 级失败回归。
2. 完成加密工作区创建/打开/导入 UI。已完成创建时可选加密、打开或导入加密工作区时的密码输入与错误反馈。
3. 真实 Windows 环境验证 NSIS、portable、数据库读写、导入导出和文件监听。

验收：AI 不可用不影响核心闭环；Windows 安装后可完成完整流程。

## 非 MVP

阅读路径自动生成、全局自然语言搜索、Agent 自动修改图谱、协作同步、跨设备云端服务、通用实体识别均移至后续版本。
