# 07 UI 交互设计

状态：0.1 交互规范。

## 1. 信息架构

```text
工作台
探索
主题画板
实验性材料问答
设置：文件夹来源 / 模型与隐私 / 工作区导入导出
```

工作台仍是首屏；材料卡点击进入探索。探索是“发现关系”的主入口，主题画板是“整理与编辑关系”的主入口。问答作为侧栏一级的“问答（实验）”页面，不承担导入或建图职责，也不出现在工作台内。

## 2. Explorer

三栏固定布局：

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 左栏 | 文件/材料列表 | 选中材料，不丢失当前工作区上下文 |
| 中栏 | 标题、来源、可阅读正文 | 依据材料类型渲染；长文本独立滚动 |
| 右栏 | 至多 5 条关联材料 | 默认按关系状态和分数排序 |

关系卡显示名称、关系类型、强度和四个图标操作：查看证据、固定、隐藏、AI 解释。操作使用图标按钮并提供 tooltip；固定后的按钮禁用。点击目标材料在同一 Explorer 内导航。

### 证据展开

展开后按证据分条显示“显式引用”或“共享实体”的人类可读说明。后续版本可依据 offset 高亮正文；0.1 至少保留证据文本和材料跳转。AI 解释显示为独立小块，明确其为可选解释，不覆盖本地证据。

### 空态与错误

- 没有材料：提示导入或新建材料。
- 没有关系：说明不会为无证据材料强造连接。
- AI 未配置/失败：显示错误 toast，本地关系卡仍可操作。
- 材料失联：显示最后快照和失联状态。

## 3. 主题画板

- 卡片四个边均放置一对输入/输出端口，任意两端口可创建关系。
- 连线方向由拖拽起点和终点决定；样式、端口和方向刷新后保持。
- 单选卡片显示“画板卡片属性”，只编辑当前主题内的显示标题、摘要、尺寸、颜色、字体、折叠、层级、标签和备注，不修改原始材料；单选正式关系则显示关系属性，用于编辑名称、方向、端口、颜色、箭头和路径。多选不显示属性面板。
- 自动发现边不直接填满画板；用户在 Explorer 固定后才进入正式关系层。
- 无正式关系时采用网格；存在 DAG 时按真实关系层级排列，不生成编号或时间“下一步”系统边。

## 4. 可访问性与响应式

- 图标按钮都有 `title` 和可辨识的禁用状态。
- 文字不依赖颜色单独传达状态；关系类型和证据类型使用文本。
- 最小桌面宽度 980px；Explorer 各栏通过 `minmax` 防止正文与按钮重叠。
- 键盘 Esc 关闭短暂菜单/选择；文本框 Enter 行为应明确。

## 5. 验收路径

导入 `overview.md` 与被它引用的 `details.md` -> 从工作台打开 overview -> 右侧首位看到 details 和“显式引用” -> 展开证据 -> 固定 -> 打开主题画板看到正式边 -> 刷新仍保持。
